# Wyrmling: First Flight

A 3D elemental dragon action-adventure that runs in the browser. It's a love
letter to the mid-2000s "young dragon learns who he is" adventures, especially
*The Legend of Spyro: A New Beginning*, rebuilt with deeper combat and more to
find. Everything is original: the hero, the Wardens, the villains, the world
and the writing. Every model, sound and note of music is generated by code at
runtime. There are no asset files.

**Play it: https://imyala.github.io/marble-story/**

```bash
npm install
npm run dev      # opens http://localhost:5173/dev.html
```

## The story

The dragons of Veyra kept their eggs in the Warden Sanctum, guarded by the four
masters of breath. On the night the twin moons swallowed the sun, the Hollow
King's shadow host burned the Sanctum. One violet egg was set adrift on the
river and raised by the fireflies of Marshlight Fen. Twelve years later the
Gloom comes looking for it.

Play as **Aster**, with your firefly foster-brother **Flick**. Rescue the
Wardens (Emberhold of Fire, Stormcrest of Lightning, Frostfang of Ice,
Stonehide of Earth), learn every breath, and face **Nyxa**, the shadow
dragoness, beneath the eclipse.

| Realm | What happens there |
| --- | --- |
| Marshlight Fen | Tutorial marsh: movement, combos, dodging, charging. Boss: Bogmaw, the Mire King |
| Warden Sanctum | The hub above the clouds. Learn Fire from Emberhold, train, spend gems, travel |
| Stormspire Falls | Cliffs, waterfalls and updrafts. Boss: Skrieka, the Last Storm Roc. Learn Lightning |
| The Frostworks | An ice forge full of lifts and gears. Boss: Forgemaster Grolm. Learn Ice |
| Stonewild Plains | Grasslands, geysers and standing stones. Boss: Graveljaw, the Burrow Wyrm. Learn Earth |
| Eclipse Keep | Nyxa's fortress. Every element, the hardest fights, the finale |

## What's deeper than the original

- **Combo trees, not button mashing.** Horn and Tail chains branch into each
  other, into a launcher (Horn, then Tail; hold Jump to rise with the enemy),
  into air juggles that keep you both aloft, and into a Ground Pound. Inputs
  are buffered, so combos come out when you mean them to.
- **Perfect dodges.** Dodge just before a hit and time slows; press Horn for a
  devastating Counter. You can also bat enemy projectiles back with your horns.
- **Four elements, each with breath, burst and fury.** Fire ignites crowds,
  Lightning chains between targets and stuns, Ice builds up to a freeze, Earth
  is a point-blank blast of knockback and stagger.
- **Elemental reactions.** Freeze an enemy and hit it hard to **Shatter** it.
  Fire on a shocked enemy **Overloads** into an explosion. Ice on a burning
  one makes a **Steam Burst** that stuns a crowd.
- **Enemies that ask questions.** Shields block from the front, Shellbacks must
  be flipped, brutes have super armor and shockwaves you jump, wisps fly,
  golems have element weaknesses, Shade Knights guard and punish, and Gloom
  Totems shield every enemy near them. An attack director keeps fights readable.
- **Style meter.** Varied hits raise your rank from Spark to Legendary; higher
  ranks drop more gems and build fury faster. Getting hit costs you a rank.
- **Progression.** Spend spirit gems at Wardstones on 20 upgrades across Horns,
  Tail, Wings, Spirit and each element (a fourth combo hit, a tail cyclone, a
  third wing flap, longer Dragon Time, stronger breaths and bursts, and more).
- **Secrets worth coming back for.** Heart and Spirit shards (four raise your
  maximum health or mana) and Dragon Relics with lore, some sealed behind
  elements you learn later.
- **Dragon Trials.** Six optional challenge fights on the Sanctum training
  grounds (clear the waves in time, reach a style rank, chain reactions, take
  no hits), unlocking as you learn elements. First clears pay big.
- **Dragon Time.** Hold C to slow the world while you keep moving.

## Controls

| Action | Keyboard and mouse | Gamepad |
| --- | --- | --- |
| Move / camera | WASD / mouse | Left stick / right stick |
| Jump, flap, glide | Space (hold after a flap to glide) | A |
| Horn attack | Left mouse (or J) | X |
| Tail attack | E (or L) | Y |
| Breath | Hold right mouse (or K) | RT |
| Burst | Q (or U) | LB |
| Fury (when the ring is full) | X | Back |
| Dodge / hold to charge | Shift | B |
| Dragon Time | Hold C | LT |
| Lock on | Tab or middle mouse | RB |
| Change element | 1 to 4, mouse wheel, R | D-pad |
| Interact | F | L3 |
| Pause | Esc | Start |

Click the game to capture the mouse; Esc releases it. Options cover volume,
camera sensitivity and inversion, screen shake, damage numbers, auto camera,
graphics quality and difficulty (Story, Adventurer, Legend).

## Development

| Command | What it does |
| --- | --- |
| `npm run dev` | Dev server with hot reload |
| `npm run build` | Typecheck, production build into `dist/`, mirrored into `play/` |
| `npm test` | Unit tests: collision, statuses and reactions, style, progression, terrain |
| `npm run check` | Typecheck and unit tests |
| `npm run smoke` | Builds, serves `dist/`, and plays the real game in headless Chromium |
| `npm run play <scenario>` | Runs `scripts/scenarios/<scenario>.mjs` against the dev server |

URL parameters for development: `?level=<id>` skips the title and loads a realm
(`fen`, `sanctum`, `falls`, `frostworks`, `plains`, `keep`), `&cp=<wardstone>`
starts at a checkpoint, `&seed=<n>` makes random rolls reproducible,
`&quality=low|medium|high` overrides graphics, and `&maxdt=0.25` lets slow
software rendering keep real time in automated tests.

The site is published by `.github/workflows/pages.yml` on every push to
`main`. GitHub Pages can serve the repo two ways and this one works under
both: with the GitHub Actions source the workflow publishes `dist/`; with the
older deploy-from-a-branch source, the root `index.html` forwards to `play/`,
a pre-built copy committed alongside the source (CI fails if it goes stale).

## Layout

```
src/core/      loop helpers, input (keyboard, mouse, gamepad), synthesized audio, RNG
src/world/     collision, terrain shaper, level runtime and the Builder level API
src/render/    renderer and bloom, sky, water, terrain meshes, instanced scenery
src/fx/        particles, lightning ribbons, swooshes, shockwaves, flashes
src/player/    dragon rig, player controller and combos, elements, Flick
src/combat/    statuses and reactions, style meter
src/enemies/   enemy AI, roster, models, and one file per boss
src/entities/  projectiles, gems, and props (gates, switches, torches, platforms...)
src/levels/    one file per realm, plus shared story helpers
src/game/      the game loop, camera, progression and saves, story text
src/ui/        HUD, dialogue, menus
tests/         unit tests
scripts/       build finisher, smoke test and the scenario playtest harness
```

Levels are plain code against the Builder API in `src/world/level.ts`:
terrain is a stack of features (islands, paths, pits, holes), and every
structure, enemy, puzzle, secret and conversation is one call. `src/levels/fen.ts`
is the most complete example.

## A note on originality

This is a fan tribute to a genre and one game in particular, made for fun and
not for sale. The mechanics are inspired by it; the names, characters, story,
dialogue, designs, art and audio are this project's own, and no assets or text
from any commercial game are used.
